# Briefly — AI-Powered Browser Assistant

## 1. Overview

Briefly is an AI-powered browser extension that enables users to understand web content faster by highlighting text directly on webpages and generating concise summaries using Large Language Models (LLMs). Built with React, TypeScript, FastAPI, and Groq APIs, Briefly aims to improve reading, research, and productivity through seamless in-browser AI assistance.
